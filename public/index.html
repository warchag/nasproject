📸 แกลเลอรีรูปภาพและวิดีโอ (Photo Gallery & Media Center)

🖼️

ยังไม่มีรูปภาพหรือวิดีโอในระบบ

เมื่อคุณอัปโหลดไฟล์รูปภาพ (`.jpg`, `.png`, `.webp`) หรือวิดีโอ (`.mp4`, `.mov`) ระบบจะนำมาแสดงในแกลเลอรีนี้โดยอัตโนมัติ

📋 กระดานคลิปบอร์ดส่งข้อความ/ลิงก์ข้ามเครื่อง (Cross-Device Clipboard & Snippet Hub)

ส่งลิงก์ยาวๆ โค้ด หรือข้อความระหว่างมือถือและคอมในวง LAN ทันทีโดยไม่ต้องทักแชทหาตัวเอง

📜 ประวัติการใช้งานระบบ & ความปลอดภัย (Activity Audit Logs & Brute-force Protection)

บันทึกทุกเหตุการณ์สำคัญพร้อมหมายเลข IP และระบบบล็อก IP อัตโนมัติเมื่อล็อกอินผิดเกิน 5 ครั้งใน 15 นาที

🛡️

สถานะการป้องกัน Brute-force IP Lockout (ล็อกนาน 15 นาทีเมื่อรหัสผิดครบ 5 ครั้ง)

กำลังตรวจสอบรายการ IP ที่เฝ้าระวัง...

🔍 ค้นหาไฟล์ข้ามโฟลเดอร์ & ตรวจจับไฟล์ซ้ำ (Fast File Indexing & Duplicate Detector)

ค้นหาไฟล์ทุกโฟลเดอร์ในเสี้ยววินาทีด้วย SQLite Index หรือสแกนหาไฟล์ที่ซ้ำกันเพื่อคืนพื้นที่ว่าง

📄

ค้นหาคำข้างในเนื้อหาไฟล์ (Full-Text Content Grep Search)

สแกนหาข้อความ โค้ด หรือคำสำคัญที่อยู่ข้างในไฟล์ (`.txt`, `.md`, `.csv`, `.json`, `.js`, `.py`, `.log` ฯลฯ) พร้อมแสดงเลขบรรทัด

WebDAV Network Drive (เชื่อมต่อเป็นไดรฟ์บนคอม/มือถือ)

เข้าถึงและจัดการไฟล์ใน NAS ได้โดยตรงจาก Finder หรือ Windows Explorer ไม่ต้องเปิดเว็บ

🍎 วิธีต่อบน macOS (Finder): กด Cmd + K ใน Finder → วาง URL ด้านบน → กด Connect → ใส่ชื่อผู้ใช้และรหัสผ่าน NAS ของคุณ
🪟 วิธีต่อบน Windows (Explorer): คลิกขวาที่ This PC → เลือก Map network drive... → วาง URL ด้านบนและติ๊ก Connect using different credentials
📱 วิธีต่อบน iOS / Android: ใช้แอปจัดการไฟล์ที่รองรับ WebDAV (เช่น FE File Explorer, Documents, CX File Explorer) แล้วใส่ URL ด้านบน

📦 ไฟล์สำรองข้อมูลของระบบ (Backup Snapshots — `storage/backups/`)

สามารถกดสร้าง Snapshot ทันทีเพื่อบีบอัดไฟล์ทั้งหมดเก็บเป็นชุดสำรองข้อมูล `.ZIP`

🔗 ลิงก์แชร์ดาวน์โหลดสาธารณะ (`/s/:token`)

จัดการลิงก์ที่คุณแชร์ให้บุคคลภายนอกดาวน์โหลดไฟล์ ดูจำนวนครั้งที่ถูกดาวน์โหลด คัดลอกลิงก์ หรือกดยกเลิกลิงก์ได้ทันที

🔗

ยังไม่มีลิงก์แชร์ดาวน์โหลด

กดปุ่ม "🔗 แชร์" บนไฟล์หรือโฟลเดอร์ใดก็ได้ในหน้าไฟล์ทั้งหมดเพื่อสร้างลิงก์แชร์สาธารณะ

📥 ลิงก์รับฝากไฟล์จากบุคคลภายนอก (File Drop / Upload Requests — `/d/:token`)

ส่งลิงก์ให้เพื่อนหรือลูกค้าอัปโหลดไฟล์ส่งเข้ามาในโฟลเดอร์ NAS ของคุณได้โดยตรงโดยไม่ต้องมีบัญชี NAS

📈 วิเคราะห์การใช้พื้นที่เชิงลึก (Deep Storage Analyzer & Top Largest Files)

เจาะลึกว่าไฟล์ประเภทใดและโฟลเดอร์ใดใช้พื้นที่มากที่สุด พร้อมจัดอันดับ 20 ไฟล์ที่มีขนาดใหญ่ที่สุดใน NAS

📊

สัดส่วนพื้นที่แยกตามประเภทไฟล์ (Storage by Category)

วิเคราะห์จากไฟล์ทั้งหมดในพื้นที่จัดเก็บของคุณ

📂

10 อันดับโฟลเดอร์ที่ใช้พื้นที่มากที่สุด (Top Folders by Size)

คลิกที่โฟลเดอร์เพื่อเปิดดูไฟล์ภายในได้ทันที

🏋️

Top 20 ไฟล์ที่มีขนาดใหญ่ที่สุดใน NAS (Largest Individual Files)

จัดการไฟล์ขนาดใหญ่เพื่อคืนพื้นที่ว่างได้อย่างรวดเร็ว

🗑️ ถังขยะ (Recycle Bin)

ไฟล์ที่ถูกลบจะถูกเก็บพักไว้ที่นี่ คุณสามารถกู้คืนกลับไปยังโฟลเดอร์เดิม หรือลบออกถาวรเพื่อคืนพื้นที่ Disk

✨

ถังขยะว่างเปล่า

ไม่มีไฟล์หรือโฟลเดอร์ที่ถูกลบค้างอยู่ในระบบ

👥 จัดการบัญชีผู้ใช้และโควตาพื้นที่ (User Management & Storage Quota)

สร้างบัญชีแยกสำหรับสมาชิกในบ้าน โดยผู้ใช้ทั่วไปจะมีโฟลเดอร์ส่วนตัวแยกกัน (`storage/files/Users/{username}`) และจำกัดโควตาพื้นที่ได้

🛡️

นโยบายการจำกัดนามสกุลไฟล์อัปโหลด (File Extension Filter Policy)

โดยค่าเริ่มต้น NAS มาตรฐานจะอนุญาตทุกนามสกุลไฟล์ แต่แอดมินสามารถตั้งค่าบล็อกไฟล์อันตราย (Blocklist) หรือจำกัดเฉพาะนามสกุลที่อนุญาต (Allowlist) ได้
